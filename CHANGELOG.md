# Changelog

## 0.1.0

Prepared the initial MIT public source release of **XNET~ — LOOP BACK!** by Felix Xavier Lopez.

- HCE (Hash-Addressed Capsule Encoding) source capsules, full-hash indexes and separate Python/Rust evidence stores.
- Caller-owned context and durable session handoff interfaces.
- Bounded inert repair evaluation and validation-gated procedural/scaffold memory.
- Strict changed-file adaptive repair admission with harness-owned bundle assembly, provenance and semantic no-op rejection.
- Native Rust HCE/HALO contracts with pinned Python-compatible vectors.
- Caller-supplied bounded learning epochs with uncertainty and promotion gates.
- Per-configuration HALO policy and synthetic utility tests.
- Optional Rust SDK and independent Jcode adapter workspace.
- Portable in-memory Python CLI demonstration.
- Durable outer loop, public archive projections and borrowed Start/Stop controls.
- Jcode history/sphere/learning, offline bridge and mobile proof interfaces.
- Fast learning epoch/artifact guards, finite home tasks and exposure accounting.
- Local provider context/citation contracts and uncompiled Apple/Windows bridge references.
- Local-disk/optional Proton blueprint and explicit portable coverage inventory.
- Exclusive parallel Rust test fixtures and individually enforced native CI exit checks.
- Replay-bounded Legions assignments bound to a caller-authenticated coordinator identity, plus HMAC-authenticated result-receipt contracts.
- A local component inventory and caller-fetched read-only checker with a pinned Jcode v0.91.0 lane. The security review disabled unsafe staging, apply and rollback paths before release.
- A source-only SwiftUI iPhone scaffold with protected local source cards and explicit home-host routing controls.
- Blind Repair 50 frozen comparison machinery and the first retained negative transfer result: Raw 32/50, Retrieval 27/50, Full XNET~ 29/50.
- Exact release inventory generation, provenance review, security policy, contribution templates, architecture visuals and evidence-classified build timeline.

The public peer configuration uses operator, assistant and peer. Start new
public roots; existing private pilot roots are not migrated or rewritten.
This source release includes reviewed adjacent scripts and targets installation
from a source checkout. It is not a standalone wheel or PyPI publication.
Utility test counts are not model capability or benchmark scores.

The Blind Repair 50 battery is a custom synthetic SWE-style benchmark, not official SWE-bench. Its first preregistered uplift gate failed, so v0.1.0 makes no harness-uplift or flagship-parity claim.
